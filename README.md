# The Distant Gaming Studio

This repository contains the source code for **The Distant Gaming Studio** website, a collection of browser-based games.

## 🌐 Where is it hosted?

This website is hosted on **GitHub Pages** and can be accessed at:

### **[https://aditya-sarna.github.io/thedistantgamingstudio.github.io/](https://aditya-sarna.github.io/thedistantgamingstudio.github.io/)**

## 📝 About

The Distant Gaming Studio is a showcase of various games including:
- Falling Bird
- Tomb Raider
- Catch
- Space Destroyer
- Jumpy Platform
- Bobo the Monkey
- Chicken Run
- Jet Pack Jenny
- Tic Tac Toe
- Pac Man

## 🔗 Repository

- **GitHub Repository**: [https://github.com/Aditya-Sarna/thedistantgamingstudio.github.io](https://github.com/Aditya-Sarna/thedistantgamingstudio.github.io)

## 📄 Files

- `index.html` - Main landing page with game gallery
- `tic tac toe.html` - Tic Tac Toe game page
- `pacman.html` - Pac Man game page
- Various image files for game thumbnails and slideshow

## 🚀 How to Access

Simply visit the hosted link above in any modern web browser. No installation required!
